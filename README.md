# SecureCode Inspector 🛡️

A cute, GUI-based cybersecurity tool that scans Python, JavaScript, Java, and C++ code for vulnerabilities.  

## Features

- 🌈 Risk colors for HIGH / MEDIUM / LOW vulnerabilities
- 🌙 Dark / Light mode toggle
- 🖱 Hover over file to see full path
- 📊 Risk dashboard
- ✅ Shows "No vulnerabilities detected" when clean
- 🔐 Detects hardcoded secrets, eval, weak hashing, SQLi patterns, system calls, and more

## How to Run

1. Clone the repo
2. Create a virtual environment and activate it
3. Install dependencies: `pip install PyQt6 reportlab`
4. Run GUI: `python main_gui.py`
5. Select any project folder to scan
